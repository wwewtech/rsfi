# Интеграция проекта с платформой OpenScience

## Что такое OpenScience?

[OpenScience](https://github.com/synthetic-sciences/openscience) — это open-source платформа (AI workbench), созданная специально для автоматизации научных исследований. Проект разрабатывается командой Synthetic Sciences и позиционируется как открытая альтернатива проприетарным научным ИИ-ассистентам.

**Ключевые особенности платформы:**
1. **Агностичность к моделям (Model-Agnostic):** Платформа позволяет "на лету" переключаться между разными LLM (GPT-4, Claude, DeepSeek, локальные Llama-3), направляя каждый запрос к наиболее подходящей модели.
2. **Полный цикл исследования (Full Research Loop):** Среда объединяет в себе поиск литературы, генерацию гипотез, написание и запуск Python-кода, анализ данных и финальную верстку научной статьи.
3. **Научные интеграции:** Встроенный доступ к базам данных (включая **arXiv** для ML/CS статей) и более 250 специализированных "навыков" (skills) для работы с научными фреймворками.
4. **Приватность:** Все вычисления и запуск кода (включая работу с API-ключами) происходят на вашей локальной инфраструктуре.

## Как OpenScience может помочь развитию проекта RSFI?

Твоя работа по выявлению семантического дрейфа с использованием римановой геометрии (RSFI) находится на стыке сложной математики и практического машинного обучения. Использование OpenScience может кардинально ускорить переход от текущего Proof-of-Concept к полноценной публикации уровня NeurIPS или ACL.

Вот 4 конкретных сценария применения платформы для твоего проекта:

### 1. Автоматизация бенчмаркинга на реальных LLM-эмбеддингах
В `test3_advanced.py` и `test4_subspace.py` мы имитировали LLM-эмбеддинги через LSA (TF-IDF + Random Projection). Для настоящей статьи тебе нужно прогнать фильтр через реальные векторы современных моделей.
*   **Как поможет OpenScience:** Платформа позволяет написать скрипт, который в едином цикле обратится к API OpenAI (`text-embedding-3-small`), Mistral и локальной Llama-3, соберет реальные векторы для твоих датасетов угроз, прогонит их через твой фильтр RSFI и автоматически построит ROC-AUC графики для сравнения.

### 2. Подготовка обзора литературы (Literature Review)
В `source.md` у тебя уже есть список базовой литературы по римановым многообразиям и NLP. Но для хорошей статьи нужен глубокий анализ конкурентов (LLaMA Guard, методы Abliteration).
*   **Как поможет OpenScience:** Благодаря интеграции с arXiv, платформа может автоматически "прошерстить" последние статьи 2023-2024 годов по темам *Contextual Drift, Sycophancy, Jailbreak Detection*, извлечь оттуда метрики конкурентов (Latency, TPR, FPR) и сгенерировать готовую сравнительную таблицу для твоей статьи.

### 3. Написание и верстка финальной научной статьи
У тебя сейчас есть отличные "куски" текста (`introduce.md`, `math.md`) и логи из Python-скриптов. Их нужно собрать в единый связный академический формат.
*   **Как поможет OpenScience:** Это одно из главных назначений платформы. ИИ-агент внутри OpenScience может взять твои markdown-файлы, результаты тестов (где доказано, что `test4` успешно ловит Zero-Day атаки в многомерном подпространстве) и собрать из них полноценный черновик статьи, отформатированный по стандартам IEEE или LaTeX-шаблонам NeurIPS.

### 4. Разработка многомерных якорей угроз (Threat Subspace)
Для `test4_subspace` нужны хорошие текстовые якоря (Anchor vectors), которые покрывают максимум типов состязательных атак (Jailbreak, Roleplay, Prompt Injection).
*   **Как поможет OpenScience:** Ты можешь поручить агенту сгенерировать 50-100 высококачественных, изощренных Jailbreak-промптов на основе существующих открытых датасетов (JailbreakBench). Эти промпты станут идеальным калибровочным корпусом для построения матрицы $Q_{thr}$ в твоем касательном пространстве.
