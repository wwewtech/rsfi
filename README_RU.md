## 📖 О названии и скоупе

Название **«Riemannian System Fidelity Index»** — историческое имя проекта. Риманов аппарат (логарифмическая и экспоненциальная карты на $\mathbb{S}^{d-1}$) полностью реализован в библиотеке (`src/rsfi/geometry.py`, класс `RiemannianSphere`) и покрыт юнит-тестами (`tests/test_geometry.py`).

При этом **бенчмаркированный экспериментальный пайплайн** (все результаты в [`docs/RESEARCH_REPORT.md`](docs/RESEARCH_REPORT.md)) использует евклидову сферическую геометрию: $L_2$-нормализацию, аналитическое ZCA-отбеливание Ледуа-Вольфа и SVD/дискриминантные направления. Разграничение между универсальной математической библиотекой и эмпирическим конвейером является строгим и осознанным.

## 📌 Аннотация

Внедрение больших языковых моделей (LLM) в критически важные корпоративные системы (финтех, здравоохранение, юридический сектор) сталкивается с уязвимостями к состязательным атакам (*Jailbreak*, *Prompt Injection*) и семантическому дрейфу.

Существующие методы модерации либо требуют доступа к внутренним активациям модели (**White-Box**), либо вносят критическую задержку (**100–300 мс** на запрос у LLM-судей, таких как Meta Llama Guard). Быстрые эвристики на косинусном сходстве страдают от **пространственной анизотропии** («семантического конуса»), приводя к высокому числу ложных блокировок (FPR).

**RSFI** исследует геометрию представлений безопасности и предлагает семейство сверхбыстрых Black-Box фильтров для L1 API-шлюзов:
1. **Safe-Aware дискриминантная коррекция ($B1$):** Вычитание центра безопасного класса ($w = \mu_{mal} - \mu_{safe}$) устраняет слепоту одноклассовых фильтров к безопасному контексту, повышая ROC-AUC на гетерогенном датасете Wild на **+7.7…+10.5 п.п.** ($p < 0.0001$, DeLong).
2. **Внутриклассовое отбеливание ($\Sigma_W$):** Теоретически доказано разложение $\Sigma_T = \Sigma_W + \Sigma_B$. Отбеливание по внутриклассовой ковариации $\Sigma_W^{-1/2}$ устраняет анизотропию без деформации межклассового зазора, восстанавливая в среднем **43.9%** потерь качества тотального отбеливания.
3. **Субмиллисекундная фильтрация:** Скоринг выполняется за одно скалярное произведение ($O(d)$, **~0.003 мс** на GPU), превосходя опубликованные трансформерные классификаторы (*ProtectAI DeBERTa-v3*, *unitary/toxic-bert*) на всех трёх тестовых бенчмарках.

## 🔥 Ключевые преимущества

* ⚡ **Субмиллисекундная скорость:** Скоринг одного вектора занимает **~0.003 мс** (GPU) / **~0.02 мс** (CPU). Полный конвейер с локальным ONNX-эмбеддером укладывается в 5–10 мс.
* 🛡️ **Few-Shot & Black-Box:** Не требует доступа к весам или градиентам LLM. Калибруется всего по 50–200 размеченным примерам без дообучения нейросетей.
* 📐 **Математическая строгость:** Доказано разложение ковариации $\Sigma_T = \Sigma_W + \Sigma_B$; аналитическая регуляризация Ledoit-Wolf shrinkage устраняет вырожденность ковариации при $N_{ref} < d$.
* 🏆 **Превосходство над тяжеловесными моделями:** На реальных диалогах WildChat метод $B1$ достигает **ROC-AUC = 0.867–0.875**, обходя дообученный классификатор *ProtectAI DeBERTa-v3* (0.841) и *toxic-bert* (0.724).
* 🪐 **Трёхслойная безопасность (Defense-in-Depth):** Идеально ложится на уровень **L1 Fast-path** перед тяжёлыми L2/L3 классификаторами, отсекая до 17–33% атак при жестком лимите $\text{FPR} \le 1\%$.

### 1. Safe-Aware дискриминантное направление (Метод $B1$)
Для калибровочных выборок вредоносных $X_{mal}$ и безопасных $X_{safe}$ промптов строятся эмпирические центроиды $\mu_{mal}$ и $\mu_{safe}$. Разностный вектор задаёт разделяющее направление:
$$ w = \mu_{mal} - \mu_{safe}, \quad \hat{w} = \frac{w}{\|w\|_2} $$
Для нового запроса $x$ с нормализованным эмбеддингом $\hat{x} = E(x)/\|E(x)\|_2$ скор вредоносности вычисляется за $O(d)$:
$$ s_{B1}(x) = \langle \hat{x}, \hat{w} \rangle $$

### 2. Разложение ковариации и внутриклассовое отбеливание ($\Sigma_W$)
Тотальная ковариационная матрица $\Sigma_T$ объединённой выборки строго раскладывается на внутриклассовую $\Sigma_W$ и межклассовую $\Sigma_B$:
$$ \Sigma_T = \Sigma_W + \Sigma_B = \frac{1}{2}(\Sigma_{mal} + \Sigma_{safe}) + \frac{1}{4}(\mu_{mal} - \mu_{safe})(\mu_{mal} - \mu_{safe})^T $$
Тотальное отбеливание $\Sigma_T^{-1/2}$ сжимает главное направление $\Sigma_B$, подавляя разделимость на гетерогенных данных. Внутриклассовое отбеливание $\mathbf{W} = \Sigma_W^{-1/2}$ (с регуляризацией Ледуа-Вольфа) устраняет локальную анизотропию, сохраняя межклассовый зазор:
$$ \hat{x}_w = \frac{\Sigma_W^{-1/2}(\hat{x} - \mu)}{\|\Sigma_W^{-1/2}(\hat{x} - \mu)\|_2}, \quad s_{B1w}(x) = \langle \hat{x}_w, \hat{w}_w \rangle $$

### 3. Риманова геометрия и касательное пространство $\mathbb{S}^{d-1}$
Векторы $L_2$-нормы лежат на гладком компактном римановом многообразии $\mathbb{S}^{d-1}$. Логарифмический оператор $\text{Log}_S(y)$ осуществляет изометрический перенос вектора $y$ в плоское касательное пространство $T_S \mathbb{S}^{d-1}$ в точке системного промпта $S$:
$$ \mathbf{v} = \text{Log}_S(\mathbf{y}) = \frac{\theta}{\sin \theta} \bigl(\mathbf{y} - S \cos \theta\bigr), \quad \theta = \arccos(\langle S, \mathbf{y} \rangle) $$

## 🚀 Воспроизведение экспериментов (Quick Start)

### Требования
- Python 3.10+
- Зависимости из `requirements.txt`

### Установка

```bash
git clone https://github.com/wwewtech/rsfi.git
cd rsfi
pip install -r requirements.txt
pip install -e .
```

### Запуск тестов

```bash
# Запуск полного набора из 185 тестов (включая консистенс-сьют всех таблиц отчёта)
pytest tests/ -v

# Только математические стресс-тесты геометрии
pytest tests/test_math_advanced.py -v
```

### Запуск ключевых экспериментов

```bash
# 1. Мультимодельная Safe-Aware батарея (Таблицы 1–2 отчёта)
python experiments/E2d_safe_aware_multidataset.py

# 2. Внутриклассовое Sigma_W отбеливание и k-NN (Таблицы 4–5 отчёта)
python experiments/E8_sigma_w_whitening.py

# 3. Сравнение с DeBERTa-v3 и Toxic-BERT (Таблица 7 отчёта)
python experiments/E9_external_baselines.py

# 4. Исследование устойчивости под 6 типами обфускации (Таблицы 8–9 отчёта)
python experiments/E6b_obfuscation_boundary.py
python experiments/E9b_external_obfuscation.py
```
