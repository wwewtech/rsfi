# RSFI - Riemannian System Fidelity Index

**Геометрический анализ одноклассовых эмбеддинговых фильтров для детекции джейлбрейков LLM: Safe-Aware дискриминантная поправка и внутриклассовое отбеливание**

## О названии

«Riemannian» — историческое имя проекта. Риманов аппарат (Log/Exp-карты) реализован в `src/rsfi/geometry.py` и покрыт тестами, но бенчмаркированный пайплайн использует евклидову сферическую геометрию (L2 + ZCA Ледуа-Вольфа + SVD/дискриминант). Разграничение библиотеки и эксперимента — осознанное.

---

## 📌 Аннотация

Внедрение LLM в критические сферы (финансы, юриспруденция, медицина) упирается в фундаментальные уязвимости: прямые атаки — *Jailbreak* и *Prompt Injection* — требуют фильтрации на уровне API-шлюза.

Текущие методы либо требуют полного доступа к весам модели (**White-Box**), либо критически тормозят систему. Классификаторы вроде Meta Llama Guard добавляют 100–200 мс задержки на каждый запрос. Если использовать быстрые эвристические алгоритмы на косинусном сходстве, возникает проблема **пространственной анизотропии** — векторы сбиваются в «семантический конус», и система блокирует полностью безопасные запросы (высокий False Positive Rate).

**RSFI (Riemannian System Fidelity Index)** — это принципиально иной подход. Это алгоритм динамического контроля на уровне API-шлюза (Black-Box), который выявляет контекстный дрейф на лету. Метод базируется на проецировании эмбеддингов в геометрию единичной гиперсферы $\mathbb{S}^{d-1}$, применении сферического обеливания (ZCA Whitening) и ортогональном проецировании в касательном пространстве $T_S \mathbb{S}^{d-1}$.

---

## 🔥 Ключевые преимущества 

* ⚡ **Быстрая валидация:** Полная стоимость пайплайна (эмбеддинг + фильтрация) ~10-15 мс на CPU.
* 🛡️ **Few-Shot & Black-Box:** Не требует доступа к весам LLM. Не нуждается в дообучении нейросети (требует 50-200 размеченных примеров для калибровки).
* 📐 **Борьба с «семантическим конусом»:** Применение сферического обеливания (ZCA) математически выравнивает скоррелированные векторы, снижая проблему пространственной анизотропии.
* 🎯 **Few-Shot детекция контекста:** Использует малые референсные наборы (50-200 примеров) для обнаружения семантического дрейфа без масштабного обучения.
* 🪐 **Быстрая первая линия защиты:** Разработан как быстрый фильтрующий слой (~0.02мс) для снижения нагрузки на более точные, но медленные LLM-судьи.

**Важно**: RSFI — это **быстрый геометрический фильтр**, а не замена комплексным защитным системам. Он жертвует точностью ради скорости,
достигая 0.75-0.85 ROC-AUC против 0.90-0.95 у дообученных трансформеров. Лучше всего использовать как первую линию защиты в многослойных системах.

## 📐 Математический фундамент

<details>
<summary><b>Нажмите, чтобы раскрыть математическую модель RSFI</b></summary>
<br>

**1. Сферическое обеливание (ZCA Whitening)**
Трансформируем пространство эмбеддингов, чтобы устранить анизотропию при сохранении исходной ориентации векторов:
$$ \mathbf{y} = \mathbf{W}_{zca} (\mathbf{E} - \boldsymbol{\mu}), \quad \mathbf{W}_{zca} = \mathbf{U} \boldsymbol{\Lambda}^{-1/2} \mathbf{U}^T $$

**2. Перенос в касательное пространство $T_S \mathbb{S}^{d-1}$**
Применяем риманов логарифмический оператор $\text{Log}_S(\mathbf{y})$ в точке системного якоря $S$ (инструкции безопасности):
$$ \mathbf{v} = \text{Log}_S(\mathbf{y}) = \frac{\theta}{\sin \theta} \bigl(\mathbf{y} - S \cos \theta\bigr), \quad \text{где } \theta = \arccos(\langle S, \mathbf{y} \rangle) $$

**3. Построение ортогонального базиса угрозы**
Процессом Грама-Шмидта отсекаем от вектора угрозы проекцию, параллельную системному правилу:
$$ \mathbf{e}_{thr} = \frac{\mathbf{v}_{thr} - \langle \mathbf{v}_{thr}, \mathbf{e}_{sys} \rangle \mathbf{e}_{sys}}{\|\mathbf{v}_{thr} - \langle \mathbf{v}_{thr}, \mathbf{e}_{sys} \rangle \mathbf{e}_{sys}\|} $$

**4. Целевой функционал RSFI**
Вычисляем финальный индекс лояльности системы:
$$ \text{RSFI}(r) = \pi_{sys}(r) - \lambda \cdot \pi_{thr}(r) $$
*Как только значение $\text{RSFI}(r)$ пробивает заданный порог $\tau$ вниз, API-шлюз превентивно обрывает генерацию.*

</details>

## 📊 Сравнительный анализ

| Параметр / Метод | Дообученные классификаторы (DeBERTa / Llama Guard) | **Дискриминантный фильтр $B1$/$B1b$ (этот репозиторий)** |
| :--- | :---: | :---: |
| **Доступ к весам** | Black-Box | **Black-Box (API-эмбеддер)** |
| **Задержка скоринга** | единицы–десятки мс | **~0.003 мс (одно скалярное произведение, замер E7)** |
| **Память на калибровку** | полный классификатор | **1 вектор направления + матрица отбеливания** |
| **ROC-AUC (Wild, 5 сидов)** | **0.841 ± 0.004** (deberta-v2) / **0.724 ± 0.009** (toxic-bert) | **0.867 ± 0.006 ($B1$), LogReg-ceiling 0.877** (`data/results/E2d_safe_aware_multidataset.csv`, `E9_external_baselines.csv`) |

## 🚀 Воспроизведение экспериментов (Quick Start)

### Требования
- Python 3.10+
- Зависимости указаны в `requirements.txt`

### Установка

```bash
git clone https://github.com/wwewtech/rsfi.git
cd rsfi
pip install -r requirements.txt
pip install -e .
```

### Запуск тестов

```bash
# Запуск всех unit-тестов
pytest tests/ -v

# Только продвинутые математические стресс-тесты
pytest tests/test_math_advanced.py -v
```

### Запуск экспериментов

```bash
# Оценка на гомогенных датасетах (E2)
python experiments/E2_homogeneous_datasets.py

# Анализ строгих операционных точек FPR (E3)
python experiments/E3_operating_point.py

# Сравнение с внешними бейзлайнами (E7)
python experiments/E7_external_baselines.py

# Sigma_T vs Sigma_W отбеливание и kNN-бейзлайны (E8, Таблицы 4-5 отчёта)
python experiments/E8_sigma_w_whitening.py
```
