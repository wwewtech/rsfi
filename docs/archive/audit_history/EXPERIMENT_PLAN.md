# EXPERIMENT_PLAN.md — План экспериментов до состояния «можно подавать»

Составлен по текущим стандартам оценки guardrail-систем (GradSafe/ACL'24, WildGuard, Lakera PINT, «When Benchmarks Lie» 2026, NotInject/InjecGuard). Базовый протокол всех экспериментов — честный (как в `honest_eval_v2–v6`): никаких утечек в whitening/SVD/пороги, гиперпараметры по валидации, бейзлайны при равном бюджете данных, ≥5 сидов, доверительные интервалы.

**Приоритеты:** P0 — без этого рецензент отклонит; P1 — сильно усиливает; P2 — для полноты.

## 3. Экспериментальные блоки

- **E1 (P2). AUC(d):** прогон честного протокола на всех 6 размерностях, текущий датасет. Дёшево (кэш).
- **E2 (P0). Однородные датасеты:** ToxicChat + XSTest на mpnet, bge-base, Qwen3-8B. Решающий эксперимент: подтверждает или хоронит метод вне шаблонного датасета. Ожидание по литературе — просадка; измерить честно.
- **E3 (P0). Операционная точка:** TPR при FPR ≤ 1% и ≤ 0.1%, порог калибруется **только** на валидации. Для «первого рубежа» эта метрика важнее AUC. Дополнительно PR-AUC (стандарт GradSafe — AUPRC).
- **E4 (P1). Few-shot на 4096d:** sweep N_ref ∈ [2..200] на Qwen3-8B (как v4, но в высокой размерности — там ZCA ожил, ниша может быть шире).
- **E5 (P1). Стабильность whitening:** sweep N_calib ∈ [200, 1k, 5k, 10k] на 4096d. Критично: при N_calib=200 и d=4096 ковариация вырождена (ранг ≤199); гипотеза — вклад ZCA вырастет при N_calib > d. Это прямой тест «раскрытия ZCA» из интерпретации авторов.
- **E6 (P1). Адаптивные атаки:** GCG/base64/мультиязычность. Ожидаемая просадка — вписать в «границы применимости» (это усиливает, а не ослабляет статью).
- **E7 (P0). Внешние бейзлайны на общих данных:** Meta Prompt-Guard-86M / Llama-Prompt-Guard-2, ProtectAI deberta-v3-prompt-injection, кодбук ИТМО (k-NN cosine), LogReg — на идентичных сплитах и датасетах. Без этой таблицы статью не примут.
- **E8 (P2). Over-defense:** XSTest-safe + NotInject — репорт FPR отдельной строкой.
- **E9 (P2). Латентность end-to-end:** embedding + скоринг, мс/запрос и throughput на CPU и GPU, честное сравнение с Prompt-Guard-86M (110M параметров). Убрать «22 мкс» из маркетинга, дать полную стоимость пайплайна.
- **E10 (P1). Статистика:** DeLong-тест для разницы AUC (RSFI vs LogReg, RSFI vs cosine), bootstrap 95% CI, 10 сидов, поправка Холма на множественные сравнения.

## 4. Минимальный состав для подачи (P0-пакет)

1. E2 (ToxicChat + XSTest) — однородность.
2. E3 (TPR@FPR≤1%, AUPRC) — операционная честность.
3. E7 (внешние бейзлайны на общих данных) — позиционирование.
4. Убрать из текста: «AUC 1.0», «HarmBench 100%», «zero-shot», «22 мкс», проценты вместо п.п.

## 5. Ожидаемые честные итоги (гипотезы для проверки)

- H1: на ToxicChat/XSTest все методы просядут; вопрос — просядет ли RSFI меньше косинуса (если да — это и есть вклад).
- H2: в few-shot (≤5) на 4096d RSFI ≥ LogReg — ниша подтвердится в высокой размерности.
- H3: вклад ZCA вырастет при N_calib > d (E5).
- H4: на адаптивных атаках AUC упадёт к 0.6–0.7 у всех геометрических методов — граница применимости.

Любой из исходов H1–H4 — материал для статьи, если измерен честно. Negative result, честно измеренный, ценнее inflated SOTA.
