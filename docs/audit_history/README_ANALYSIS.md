## 🎯 Главный вывод

**Проект представляет собой работающий геометрический метод детекции вредоносных промптов с реальной эффективностью 0.82-0.86 AUC (лучший результат 0.856 на 4096d), но с серьёзными методологическими проблемами в экспериментах и завышенными метриками в документации.**

### Суть в одном предложении
Метод **работает** и даёт стабильный прирост +4-6 п.п. над косинусом, но проигрывает логистической регрессии при равном бюджете данных и требует исправления всех бенчмарков (0 из 7 честных) + документации перед подачей.

## 🔥 Критически важные факты

### Что работает
✅ Математическое ядро корректно (510 строк тестов, все проходят)  
✅ SVD-подпространство даёт +4-6 п.п. над косинусом на всех моделях ≥768d  
✅ Лучший честный результат: **0.856 ± 0.009** на Qwen3-Embedding-8B (4096d)  
✅ Few-shot ниша: при N_ref ≤ 5 метод конкурентоспособен с LogReg

### Что сломано
❌ **0 из 7 бенчмарков честные** (утечки данных, k по тесту, синтетика)  
❌ Фейковые датасеты (9 текстов × 400 дублей = "HarmBench 100% accuracy")  
❌ Противоречия: AUC 1.0 vs 0.88 vs 0.86, латентность 21 мкс vs 6.4 мс  
❌ Отсутствуют критические эксперименты (однородные данные, внешние бейзлайны)

### Главная проблема
**Документация заявляет AUC 1.0 и "zero-shot", реальность — AUC 0.82-0.86 и "few-shot (50-200 примеров)", проигрыш LogReg на 2.5-5.3 п.п.**
