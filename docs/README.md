## Основные документы

| Документ | Назначение | Для кого |
|---|---|---|
| 📄 [`RESEARCH_REPORT.md`](RESEARCH_REPORT.md) | **Главный научно-исследовательский отчёт и аудит.** Полные результаты экспериментов (E1–E10, E6b, E8, E9, E9b), Таблицы 1–9, DeLong-статистика, математическое доказательство $\Sigma_T = \Sigma_W + \Sigma_B$, исследование обфускации, вердикт уровня ВАК (К2), матрица закрытия дефектов D1–D11 и хроника эволюции проекта. | Исследователи, рецензенты, диссертационный совет, ML-инженеры |
| 📐 [`math.md`](math.md) | **Математическая модель и семантическая геометрия.** Теоретический базис: риманова сфера $\mathbb{S}^{d-1}$, Log/Exp карты, сферическое обеливание, аналитическая регуляризация Ledoit-Wolf shrinkage, ортогонализация Грама-Шмидта. | Математики, ML-теоретики |
| 💼 [`BUSINESS.md`](BUSINESS.md) | **Инженерная и коммерческая архитектура.** Rust API Gateway, стратегия «Three-Clocks», задержка L1 fast-path (<1 мс), соответствие требованиям EU AI Act, B2B интеграция и ROI. | Архитекторы безопасности, бизнес, DevOps, техлиды |
