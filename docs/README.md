# Документация проекта RSFI

Навигационная карта и структура исследовательской, математической и инженерной документации репозитория.

---

## Основные документы

| Документ | Назначение | Для кого |
|---|---|---|
| [`RESEARCH_REPORT.md`](RESEARCH_REPORT.md) | **Главный научный отчёт.** Все эксперименты (E1–E10, E6b, E8, E9, E9b), Таблицы 1–9, DeLong-статистика, замеры задержки, разложение ковариации и исследование обфускации. | Исследователи, рецензенты, ML-инженеры |
| [`VAK_VERDICT.md`](VAK_VERDICT.md) | **Официальный вердикт аудита готовности к публикации.** Статус закрытия дефектов D1–D11, верификация 185 автотестов, оценка уровня ВАК (К2). | Авторы научной статьи, диссертационный совет |
| [`rsfi_final_audit_breakdown.md`](rsfi_final_audit_breakdown.md) | **Хроника аудита и доказательная база.** Детальный разбор вклада участников, эволюция гипотез от первых аномалий до 100% верифицированных фактов. | Аудиторы, исследователи, фактчекеры |
| [`PROJECT_EVOLUTION.md`](PROJECT_EVOLUTION.md) | **История развития проекта.** Хронология эволюции архитектуры: от ранних утечек данных до честной трёхслойной концепции Defense-in-Depth. | Разработчики, архитекторы систем |
| [`math.md`](math.md) | **Математический аппарат.** Теоретическая формализация: риманова сфера $\mathbb{S}^{d-1}$, ZCA-отбеливание, Ledoit-Wolf shrinkage, ортогонализация Грама-Шмидта. | Математики, ML-теоретики |
| [`BUSINESS.md`](BUSINESS.md) | **Бизнес-контекст и продакшен.** Архитектура API-шлюза на Rust, стратегия «Three-Clocks», соответствие EU AI Act, интеграция в L1 fast-path. | Архитекторы безопасности, бизнес, DevOps |
