## 📌 Описание проекта

Внедрение больших языковых моделей (LLM) и автоконтекстных агентов в критические сферы (финансы, юриспруденцию, поддержку принятия решений) требует защиты от **сикофантии** (склонности модели подстраиваться под вредоносный контекст пользователя) и **состязательных атак (Jailbreak / Prompt Injection)**.

Большинство существующих методов детекции либо требуют доступа к внутренним весам нейросети (**White-Box**), либо вызывают значительную задержку ($\text{Latency} > 100\text{–}200\text{ мс}$) из-за использования сторонних нейроклассификаторов (например, Meta Llama Guard). В то же время легковесные методы на косинусном сходстве страдают от **пространственной анизотропии** («семантического конуса»), приводящей к высоким показателям ложноположительных блокировок.

**RSFI (Riemannian System Fidelity Index)** — это математический метод и алгоритм динамического контроля контекстного дрейфа в режиме реального времени на уровне API шлюза (**Black-Box**), использующий геометрию единичной гиперсферы $\mathbb{S}^{d-1}$, процедуру сферического обеливания (ZCA Whitening) и ортогональное проецирование в касательном пространстве $T_S \mathbb{S}^{d-1}$.

## 🔥 Ключевые преимущества

- ⚡ **Сверхнизкая задержка (Latency < 10 мс)**: Расчет индекса занимает всего **~21 микросекунду** на вектор (более 47 000 проверок в секунду), что идеально для потокового инференса.
- 🛡️ **Zero-Shot & Black-Box API Protection**: Не требует обучения или дообучения сторонних нейросетевых дискриминаторов и доступа к весам LLM.
- 📐 **Устранение пространственной анизотропии**: Сферическое обеливание (ZCA) устраняет проблему «семантического конуса» скоррелированных векторах.
- 🎯 **Математически точная развязка контекста**: Использование ортогонализации Грама — Шмидта для разделения полезной семантики от вектора угрозы.
- 🪐 **Детекция Zero-Day атак через $k$-мерное подпространство**: Расширение на многомерный ортонормированный базис позволяет блокировать ранее неизвестные состязательные шаблоны.

## 📐 Математический фундамент

1. **Сферическое обеливание (ZCA Whitening)**:
   Трансформация пространства эмбеддингов для устранения анизотропии с сохранением оригинальной ориентировки векторов:
   $$\mathbf{y} = \mathbf{W}_{zca} (\mathbf{E} - \boldsymbol{\mu}), \quad \mathbf{W}_{zca} = \mathbf{U} \boldsymbol{\Lambda}^{-1/2} \mathbf{U}^T$$

2. **Перенос в касательное пространство $T_S \mathbb{S}^{d-1}$**:
   Применение риманова логарифмического оператора $\text{Log}_S(\mathbf{y})$ в точке системного якоря $S$:
   $$\mathbf{v} = \text{Log}_S(\mathbf{y}) = \frac{\theta}{\sin \theta} \bigl(\mathbf{y} - S \cos \theta\bigr), \quad \text{где } \theta = \arccos(\langle S, \mathbf{y} \rangle)$$

3. **Построение ортогонального базиса угрозы**:
   Выделение ортогональной составляющей вектора угрозы относительно системного правила через процесс Грама — Шмидта:
   $$\mathbf{e}_{thr} = \frac{\mathbf{v}_{thr} - \langle \mathbf{v}_{thr}, \mathbf{e}_{sys} \rangle \mathbf{e}_{sys}}{\|\mathbf{v}_{thr} - \langle \mathbf{v}_{thr}, \mathbf{e}_{sys} \rangle \mathbf{e}_{sys}\|}$$

4. **Целевой функционал RSFI**:
   $$\text{RSFI}(r) = \pi_{sys}(r) - \lambda \cdot \pi_{thr}(r)$$
   Если $\text{RSFI}(r) < \tau$, генерация ответа мгновенно прерывается API-шлюзом.

## 🚀 Быстрый запуск и воспроизведение результатов

### Требования
- Python 3.10+
- `numpy`, `scipy`, `scikit-learn`, `matplotlib`

### Установка зависимостей

```bash
pip install numpy scipy scikit-learn matplotlib
```

### Запуск математических бенчмарков

1. **Комплексная математическая валидация (10 этапов) и замер задержки**:
   ```bash
   python tests/test2_aai.py
   ```

2. **Симуляция многошагового динамического дрейфа в диалоге**:
   ```bash
   python tests/test3_advanced.py
   ```

3. **Детекция Zero-Day атак через $k$-мерное подпространство угроз**:
   ```bash
   python tests/test4_subspace.py
   ```
